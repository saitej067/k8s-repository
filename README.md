
# Kubernetes Production Demo

This repository contains:

- Namespace
- ServiceAccount
- Deployment
- Service
- PersistentVolumeClaim (PVC)
- ConfigMap
- Secret
- Role
- RoleBinding
- ClusterRole
- ClusterRoleBinding
- HorizontalPodAutoscaler (HPA)
- Node Selector
- Multiple Volume Mounts

## Deploy

kubectl apply -f k8s-resources.yaml
